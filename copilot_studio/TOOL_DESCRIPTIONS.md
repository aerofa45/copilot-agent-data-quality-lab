# Tool descriptions

## lookupCustomer
Use when the user provides a numeric customer ID and verified customer details are needed.

## lookupDevice
Use when the user provides a device ID such as DEV-100 and device assignment/status must be verified.

## createSupportTicket
Use only after customer ID, device ID, issue, and severity are known.
For high or critical severity, confirm intent before calling the tool.

## listSupportTickets
Use when the user explicitly asks to see tickets created during the demo session.
