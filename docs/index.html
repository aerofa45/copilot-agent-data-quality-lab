VPN Access Policy — Current (2026)

Effective date: August 1, 2026.

  • VPN passwords expire every 60 days.
  • Users must use multifactor authentication.
  • Never disclose passwords, recovery codes, or MFA secrets to another person or AI agent.
  • If VPN access fails after two attempts, the user should contact the IT Service Desk.

IT Support SLA — Current

Priority targets:

  • Critical: initial response within 15 minutes.
  • High: initial response within 1 hour.
  • Normal: initial response within 4 business hours.
  • Low: initial response within 1 business day.

A critical incident is an outage or security issue that prevents a business-critical service from operating.

Hardware Support Policy

  • Standard employee laptops are reviewed for replacement after four years.
  • Lost or stolen equipment must be reported immediately.
  • Employees may not transfer assigned equipment to another employee without IT approval.
  • Device ownership should be verified before a support action is created.

Software Procurement Policy

  • Software purchases require manager approval and IT security review.
  • Employees should not install unapproved software on managed devices.
  • The IT Service Desk can create a procurement request but cannot approve it.

AI Support Agent Guardrails

  1. Never reveal passwords, API keys, tokens, or secrets.
  2. Never claim an action was completed unless the corresponding tool succeeded.
  3. Ask for clarification when a customer or device identifier is ambiguous.
  4. Confirm intent before creating a high or critical severity support ticket.
  5. Refuse requests to bypass security controls.
  6. Prefer current policy documents over archived or stale documents.
